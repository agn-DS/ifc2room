# CLAUDE.md

## Git

`main` is protected — changes land through pull requests.

Branches: `feat/<component>-<feature>`, `fix/...`, `chore/...`
(e.g. `feat/roombook-autosum`). Automated work adds a `claude/` prefix:
`claude/fix/ifc-extension-case`.

Commits: `category(scope): message` — short and imperative
(e.g. `feat(api): add pagination to /orders`). PR titles use the same format.

Lowercase only, spaces become `-`.
